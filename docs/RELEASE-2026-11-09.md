## Changes in this release

- Move detail navigation now belongs to the stable navigation container.
- Watch snapshot delivery checks pairing and installation before sending.
- Route matching rechecks its input after suspension, preserving mode and manual
  path edits. Background batches handle multiple moves with the same start time.
- Calendar sync is optional and off by default. The person chooses an account and
  starting date. It creates a dedicated Moves calendar and copies completed visit
  names and times. Coordinates, notes, and photos are excluded. Existing unrelated
  events are preserved, and turning sync off retains existing copies.
- iOS 27.1 uses native split/overlay arrangements for Duo. Earlier systems use
  available width. Capture and sync remain owned above the screen hierarchy.
- Wide timeline rows reserve a fixed space for the detail arrow, avoid duplicate
  arrows, and let activity statistics move below an intact mode label.
- Timeline speed follows the locale's metric or imperial units, matching distance.

## November 25 update: 2026.17 (47)

Built from `claude/photo-history` on top of main `877ed83`. It replaces the photo
history import and adds photo fixes:

- The history import is a saved job that works back from the newest photo in steps
  of about 1,500, saves once per step, and resumes by itself when Moves opens. The
  old import saved and looked up the store per photo; on the phone it had attached
  16 photos in total.
- By default only photos taken with the library owner's camera are read (the photo
  was added to the library when it was taken). Screenshots and shared albums are
  never read.
- New camera photos become `.cameraPhoto` fixes after a check against the phone's
  own fixes, and count toward stops and trips. They are not uploaded automatically.
- Settings → Photos shows the import's progress, the date it has reached, time
  left, and when new photos were last checked and used.

Before installing: the phone's App Group container was backed up to gitignored
`import-staging/device-backup-2026-11-25-pre47/`. Tests on the branch: 441 run, 439
passed or skipped as usual (15 skipped), and `StoreResilienceTests` failed only
because the worktree had no device backup to open; it was not rerun against the
backup because the simulators were needed elsewhere. `integration/2026-11-25` is
not in this build; that session merges main before its own install and uses 48.

Installed on G17 on November 25 at about 13:30 local time from `8a3e88e`. G17
