## Changes in this release

- Move detail navigation now belongs to the stable navigation container.
- Watch snapshot delivery checks pairing and installation before sending.
- Route matching rechecks its input after suspension, preserving mode and manual
  path edits. Background batches handle multiple moves with the same start time.
- Calendar sync is optional and off by default. The person chooses an account and
  starting date. It creates a dedicated Moves calendar and copies completed visit
  names and times. Coordinates, notes, and photos are excluded. Existing unrelated
  events are preserved, and turning sync off retains existing copies.
- iOS 27.1 uses native split/overlay arrangements for Duo. Earlier systems use
  available width. Capture and sync remain owned above the screen hierarchy.
- Wide timeline rows reserve a fixed space for the detail arrow, avoid duplicate
  arrows, and let activity statistics move below an intact mode label.
- Timeline speed follows the locale's metric or imperial units, matching distance.
